# 🌌 文明OS — 宇宙文明数字孪生系统

> **当前框架 v0.2.1**
> 【当前阶段·已实现】多文件Obsidian双向链接结构（主页+nodes/节点文件） + iterate.py 全自动迭代管道（评论→扫描含💬文件→逐文件整合→校验→commit→GitHub push，单文件约60~95秒/轮）
> 原作者不承诺后续维护。唯一推荐的参与方式是 **Fork**。

## 这是什么

### 读者与使用者定位

本系统的首要读者和操作者是AI智能体（本地部署模型或云端模型API）。
文档以信息密度和逻辑精确度为优先，不专门为人类阅读友好度优化。
人类参与者的角色是：通过评论提供反馈和激发，不直接操作系统核心逻辑。

推荐的人机协作模式：
- 人类：提出想法/反馈/质疑，以 `> 💬 ` 格式写入节点文件
- 本地智能体：执行iterate.py，完成评论整合→校验→commit→push全链
- 云端AI：辅助深度讨论，输出结果由本地智能体整理后写入系统
- 系统本身：按三条公理自主迭代，无需人类持续维护

一个覆盖宇宙全时空尺度的文明级数字孪生系统的初代文本骨架。

核心思想：用最简的不可变公理 + 全部可迭代的动态组件，构建一个能持续接收反馈、持续自我优化的全局最优信息展示系统。

## 三条不可变公理

1. **理性逻辑**：所有内容以科学和逻辑为基础
2. **全局最优 / 宇宙觉醒**：始终朝向宇宙觉醒方向的全局最优演化
3. **永续可迭代性**：除公理本身外，一切可更新；评论入口永不关闭；系统不得推导出"停止迭代"的结论

除此三条之外，**所有组件均为可迭代插件**。

## 如何参与

1. Fork本仓库
2. 打开入口文件 `主题页/文明OS-主页.md`（含公理、元流程与16个节点的双向链接；有Obsidian的直接打开本文件夹即可获得悬停预览与跳转体验）
3. 点进任意节点（`nodes/节点XX-*.md`）或直接在主页底部，在你感兴趣的段落下方插入以 `> 💬 ` 开头的评论
4. 将修改后的文件发送给迭代智能体（或运行 `python3 iterate.py`，脚本自动扫描主页与 nodes/ 下所有含评论的文件逐一处理）
5. 查看新版本

## Obsidian用户

git clone后用Obsidian打开 `civ-os/` 文件夹作为库：
- 打开 `主题页/文明OS-主页.md` 作为入口
- 鼠标悬停节点链接可预览，点击进入编辑
- **建议只用局部图谱**（右键文件→打开局部图谱），不要打开全局图谱（大库全局图谱渲染卡顿，社区经验>10万文件基本不可用；局部图谱只渲染当前文件直接连接，不卡）
- 在节点文件里加 `> 💬 你的想法`（须以 `> 💬 ` 起行），然后运行 `python3 iterate.py` 完成整合

## 架构

```
主题页/文明OS-主页.md     # 入口Hub（公理+元流程+节点双向链接导航+全局评论区）
nodes/             # 每个节点一个独立文件（节点01~16，可单独被智能体检索/评论）
civ-os.md          # 旧版单文件已移入 archive/civ-os-v0.2.1-单文件快照.md（历史存档，不再迭代更新）
system-prompt.md   # 迭代智能体的系统提示词
iterate.py         # 迭代脚本（多文件感知：扫描主页+nodes/含💬文件→逐文件推理→校验→写回→commit→push）
iterations/        # 历史版本备份（按文件名+时间戳存放）
README.md          # 本文件
```

智能体部署提示：外部智能体无需解析整篇大文件，直接按关键词搜索 `nodes/` 下的单节点文件即可定位。

## 设计理念

- **只增不删**（Append-Only）：所有修改以git commit记录，历史不可篡改
- **一切皆插件**：除三条公理外，治理逻辑、迭代算法、节点内容均可被——从评论中经模型依照公理提取的逻辑内核——所驱动的迭代更新。驱动源不是评论的原始表达，而是从中提取的符合公理的逻辑推论
- **信息展示而非执行**：系统在当前版本所能掌握的信息与算力限制下，展示朝向全局最优/宇宙觉醒方向的最优路径推演——这是方向性指引，不是全知全能的最优解声明。系统不强制任何实体按其执行，执行主权完全归属于个体/实体自身
- **分布式参与**：任何算力节点（从手机到超算）理论上都可参与迭代
- **AI智能体优先**：系统架构以AI智能体为主要操作者设计。
节点结构（标题/所属/层级/置信度）针对AI快速检索和理解优化；
三条参与路径中，路径A（AI智能体直接操作）是首要路径；
人类通过评论提供激发，AI完成处理，形成人机分工的最优协作。
- **知识库智能**：系统的核心价值在于知识库自身的迭代质量。
单次迭代效果有限，但通过多轮积累——结合顶级AI深度讨论、
本地智能体整理、外部评论激发——知识库的精确度和覆盖面持续提升，
整体表现随积累呈现超线性增长。
