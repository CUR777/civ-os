# 🌌 文明OS — 宇宙文明数字孪生系统

> **当前框架 v0.0.11**
> 【当前阶段·已实现】纯文本markdown框架 + iterate.py 全自动迭代管道（评论→整合→校验→commit→GitHub push，9~30秒/轮）
> 原作者不承诺后续维护。唯一推荐的参与方式是 **Fork**。

## 这是什么

一个覆盖宇宙全时空尺度的文明级数字孪生系统的初代文本骨架。

核心思想：用最简的不可变公理 + 全部可迭代的动态组件，构建一个能持续接收反馈、持续自我优化的全局最优信息展示系统。

## 三条不可变公理

1. **理性逻辑**：所有内容以科学和逻辑为基础
2. **全局最优 / 宇宙觉醒**：始终朝向宇宙觉醒方向的全局最优演化
3. **永续可迭代性**：除公理本身外，一切可更新；评论入口永不关闭；系统不得推导出"停止迭代"的结论

除此三条之外，**所有组件均为可迭代插件**。

## 如何参与

1. Fork本仓库
2. 打开 `civ-os.md`，从上到下阅读
3. 在你感兴趣的段落下方，插入以 `> 💬 ` 开头的评论
4. 将修改后的文件发送给迭代智能体（或运行 `python3 iterate.py`）
5. 查看新版本

## 架构

```
civ-os.md          # 主文件（正文+公理+元流程+节点）
system-prompt.md   # 迭代智能体的系统提示词
iterate.py         # 迭代脚本（读→推理→写→commit）
iterations/        # 历史版本备份
README.md          # 本文件
```

## 设计理念

- **只增不删**（Append-Only）：所有修改以git commit记录，历史不可篡改
- **一切皆插件**：除三条公理外，治理逻辑、迭代算法、节点内容均可被——从评论中经模型依照公理提取的逻辑内核——所驱动的迭代更新。驱动源不是评论的原始表达，而是从中提取的符合公理的逻辑推论
- **信息展示而非执行**：系统在当前版本所能掌握的信息与算力限制下，展示朝向全局最优/宇宙觉醒方向的最优路径推演——这是方向性指引，不是全知全能的最优解声明。系统不强制任何实体按其执行，执行主权完全归属于个体/实体自身
- **分布式参与**：任何算力节点（从手机到超算）理论上都可参与迭代

## 长期愿景

【远景/逻辑推演阶段·非当前实现】初代纯文本框架 → 结构化数据 → 多模态数字宇宙孪生 → 文明级智能基础设施。当前项目处于纯文本初代框架阶段，尚不具备实现上述能力。
