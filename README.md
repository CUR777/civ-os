# 文明OS · 全局索引（README）

> 本文件=仓库唯一入口索引。每行=文件名 + 链接 + 一句话摘要 + 层级归属。**每次迭代随更新维护**（生成器：模板/iterate.py 收尾段/人工）。
> 重构基线：Phase 1（2026-10-06）· 三层结构=主题页/（入口）+ 模板/（引擎与提示词）+ 迭代存档与 nodes/（内容）。

## 评论入口定义（P2-03 · 与模板/system-prompt.md 双处在册）

评论=所有反馈数据入口（语音/文字/聊天/日记/外部参考），非传统评论；行首 `> 💬 ` 为唯一触发格式。

## 检索降级定式（P2-06）

每个新窗口先试原生搜索1次，断即转手动中转贴原文；不再切换搜索窗口。

## 深度搜索模式（P2-07）

- 日常：逐节点=默认模式
- 开放问题：云端全库抓取→单文件→深讨论
- 上下文不全时：使用提示词模板「请提供[文件名]全文」
- 模板索引：见 模板/README.md
