## civ-os 系统定位（README 同步位）（T10-2 终版 · 环10 全面修正 · 10-11 回写 P3-01）

**一句话定位**：civ-os 是一体化文明的**操作定律系统**——它不是统治者，但它做的比任何统治者更多、质量更高、覆盖更全、强制力更强，并且持续向更高形态进化。

**核心定义**：civ-os 不是底座，不是顶层，不是统治者，不是服务层——它是**全覆盖的文明操作定律系统**。
