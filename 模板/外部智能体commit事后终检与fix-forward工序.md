## 二、选型前置（回退 vs 保留+事后终检）

## 三、四检（逐项带盘面命令，禁以 message/版本记录自证）

#模板-外部智能体commit事后终检与fix-forward工序V20261016112400000+A4
| 检 | 内容 | 正形命令 | 陷阱 |
|---|---|---|---|
| A 保护区 | 受保文件原文零触碰 | `git show <sha> -- <受保文件>`=0 行；有触碰则切片全等复比 | 行号区间法禁用（历史位移案型）；边界多形取 min |
| B 声称内容 | 逐条断言→diff 盘面 | `git diff <sha>~1 <sha>` 全量读 + 对每条声称 grep 回位 | **断言>实据案型**：message/版本记录声称「已新增X」而正文无X——版本记录属账面，唯一证人=diff |
| C 计数 | 账面计数行 vs 实取 | `git ls-tree -r HEAD --name-only | wc -l` 对 README 账面行 | 账面滞后=提示不硬拦，勘正注行必补 |
| D 卫生 | 受限词/私有残留/死链 | 全 diff 新增行扫受限词表+绝对路径私产面 | 新术语随批登记，防暗改口径 |

## 四、fix-forward 与登记
