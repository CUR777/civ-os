# 双向链接拆分范式（D13 · 重要 · 定稿 10-10 · P2-53）

> 定稿（回3A16-1/D13/B19）：两节点有共通细节 → 拆出**独立共通文件** → 两节点各放双向链接指向该文件 → 共通文件独立迭代（**更新一处全局生效**）→ 各节点在链接下方写**本节点特有特化备注**。

## 拆分判定条件
- **正判**：共通内容字数 ≥ 各自特化备注字数（至少持平或超过）→ 值得拆。
- **反例**：共通版本字数远少于各处特化备注 → 不值得拆，保留原位（防碎片化）。

## 执行工序（全库重构分批推进 · C8 同族）
1. 指纹扫描定位交集段（≥25 字正文行跨文件重复即候选）；
2. 按判定条件裁决拆/不拆（结论随表登记，不拆也留理由）；
3. 拆出文件命名 `nodes/共通-<主题>.md`，头部带血缘行（双链回两父节点）+created_at/version_tag；
4. 父节点原位替换=链接行+特化备注行；
5. 复扫验证交集清零（该对文件）+坏链扫描不新增。
